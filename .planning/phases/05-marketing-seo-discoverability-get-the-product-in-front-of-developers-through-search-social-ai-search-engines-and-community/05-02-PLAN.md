<!-- Competitor data from docs/research/COMPETITIVE-ANALYSIS.md and 05-RESEARCH.md: -->

**sigbit (MCP Auth Proxy)**
- Free, open-source
- OAuth authentication only (no RBAC, no audit, no rate limiting)
- Drop-in proxy (same deployment model as ours)
- Good for: solo devs who only need auth, no compliance requirements
- GitHub: theailanguage/mcp-auth-proxy

**Kong Gateway**
- Enterprise-grade API gateway
- Requires Kubernetes or complex infrastructure
- Full feature set (auth, RBAC, rate limiting, logging)
- $500+/mo minimum for MCP-relevant features
- Overkill for small teams; requires dedicated platform team
- Not MCP-specific -- general-purpose API gateway

**Cloudflare (MCP-related offerings)**
- Cloudflare Access / Zero Trust
- Vendor lock-in to Cloudflare ecosystem
- Not self-hosted (SaaS-only)
- No MCP-specific features (JSON-RPC parsing, tool-level RBAC)
- Good for: teams already on Cloudflare who need basic auth

<!-- Pricing from CLAUDE.md: -->

Pro: $49/mo, 5 servers, 200 req/min, file audit with rotation
Enterprise: $199/mo, unlimited servers, unlimited rate, all features
