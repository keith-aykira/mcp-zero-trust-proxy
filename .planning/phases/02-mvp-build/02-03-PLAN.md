Create `internal/auth/pkce.go`:
- `func GenerateCodeVerifier() (string, error)` — 32 random bytes, base64url-encoded (no padding), 43 chars. Uses crypto/rand.
- `func GenerateCodeChallenge(verifier string) string` — SHA256 hash of verifier, base64url-encoded (no padding). This is the S256 method per RFC 7636.
- `func VerifyCodeChallenge(verifier, challenge string) bool` — regenerates challenge from verifier, compares with constant-time comparison (subtle.ConstantTimeCompare).

Create `internal/auth/providers.go`:
- `type OAuthProvider struct` — Name, AuthURL, TokenURL, UserInfoURL, Scopes []string
- `func GitHubProvider() OAuthProvider` — GitHub OAuth endpoints (authorize: github.com/login/oauth/authorize, token: github.com/login/oauth/access_token, userinfo: api.github.com/user). Scopes: ["read:user", "user:email"].
- `func GoogleProvider() OAuthProvider` — Google OIDC endpoints (accounts.google.com). Scopes: ["openid", "email", "profile"].
- `func OIDCProvider(issuerURL string) (OAuthProvider, error)` — discover endpoints from .well-known/openid-configuration. Returns error if discovery fails.

Create `internal/auth/oauth.go`:
- `type Authenticator struct` — implements proxy.Authenticator interface. Holds provider config, http.Client, session store reference, PKCE state cache (sync.Map of state -> {verifier, created_at}).
- `func NewAuthenticator(cfg *config.AuthConfig, sessionStore *SessionStore) (*Authenticator, error)` — constructs from config, selects provider by name.
- `func (a *Authenticator) Authenticate(r *http.Request) (*proxy.ClientIdentity, error)` — checks Authorization header for Bearer token. Validates token by calling provider's userinfo endpoint. On success, returns ClientIdentity with ClientID (user ID from provider), Email, Role (from config mapping), SessionID (from session store).
- `func (a *Authenticator) HandleAuthStart(w http.ResponseWriter, r *http.Request)` — generates PKCE verifier/challenge, stores in state cache, redirects to provider's authorize URL with code_challenge and code_challenge_method=S256.
- `func (a *Authenticator) HandleCallback(w http.ResponseWriter, r *http.Request)` — receives auth code, retrieves PKCE verifier from state cache, exchanges code+verifier for token via provider's token endpoint, creates session, returns token to client.
- State cache entries expire after 10 minutes (cleanup on access).
- Token validation caches valid tokens for 5 minutes (in-memory map with TTL) to avoid hitting userinfo endpoint on every request.

Use standard library `net/http` for OAuth HTTP calls. Do NOT use `golang.org/x/oauth2` -- it adds complexity and doesn't support PKCE natively for the code exchange. The manual implementation is simpler and more transparent for this use case.

Write PKCE tests first, then OAuth tests, then implement.

Create `internal/auth/session.go`:

- `type Session struct` — ID (string, UUID v4), ClientID (string), Role (string), Email (string), CreatedAt (time.Time), LastAccess (time.Time), ExpiresAt (time.Time), Data (map[string]interface{} for session-scoped storage).
- `type SessionStore struct` — in-memory store using sync.RWMutex + map[string]*Session. Holds default TTL (configurable, default 1 hour).
- `func NewSessionStore(ttl time.Duration) *SessionStore` — creates store, starts background goroutine for expired session cleanup (runs every minute).
- `func (s *SessionStore) Create(identity *proxy.ClientIdentity) (*Session, error)` — generates UUID v4 session ID using crypto/rand, stores session with TTL, returns session. Sets identity.SessionID.
- `func (s *SessionStore) Get(sessionID string) (*Session, error)` — returns session if exists and not expired. Refreshes LastAccess and extends ExpiresAt on successful access. Returns error if expired or not found.
- `func (s *SessionStore) Delete(sessionID string)` — removes session (for logout).
- `func (s *SessionStore) GetByClientID(clientID string) ([]*Session, error)` — returns all active sessions for a client (for admin visibility).
- `func (s *SessionStore) cleanup()` — removes expired sessions. Called by background goroutine.
- `func (s *SessionStore) Stop()` — stops cleanup goroutine (for clean shutdown).

Session isolation guarantee: each session's Data map is independent. No shared references between sessions. ClientID+SessionID combination uniquely identifies a session boundary.

Use `crypto/rand` for UUID generation (not math/rand). Format: 8-4-4-4-12 hex characters.

Write tests FIRST (RED) including a race condition test with `-race` flag, then implement (GREEN).
