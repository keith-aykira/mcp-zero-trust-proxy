Create `internal/config/types.go`:
```go
type Config struct {
    Server   ServerConfig   `yaml:"server"`
    Auth     AuthConfig     `yaml:"auth"`
    Roles    []RoleConfig   `yaml:"roles"`
    RateLimit RateLimitConfig `yaml:"rate_limit"`
    Audit    AuditConfig    `yaml:"audit"`
    Logging  LogConfig      `yaml:"logging"`
}

type ServerConfig struct {
    UpstreamURL string `yaml:"upstream_url"` // Required: MCP server URL
    ListenAddr  string `yaml:"listen_addr"`  // Default: ":8080"
}

type AuthConfig struct {
    Provider     string `yaml:"provider"`      // "github", "google", "oidc"
    ClientID     string `yaml:"client_id"`     // OAuth client ID
    ClientSecret string `yaml:"client_secret"` // OAuth client secret (or env var ref)
    IssuerURL    string `yaml:"issuer_url"`    // OIDC issuer URL
    RedirectURL  string `yaml:"redirect_url"`  // OAuth redirect URL
}

type RoleConfig struct {
    Name         string   `yaml:"name"`          // "admin", "readonly", "restricted"
    AllowedTools []string `yaml:"allowed_tools"`  // Tool names this role can call (empty = all for admin)
    DenyTools    []string `yaml:"deny_tools"`     // Tool names explicitly denied
}

type RateLimitConfig struct {
    RequestsPerMinute int `yaml:"requests_per_minute"` // Default: 100
    BurstSize         int `yaml:"burst_size"`          // Default: 10
}

type AuditConfig struct {
    Enabled  bool   `yaml:"enabled"`   // Default: true
    Output   string `yaml:"output"`    // "stdout", "file", "both" — default: "stdout"
    FilePath string `yaml:"file_path"` // Path for file output
}

type LogConfig struct {
    Level  string `yaml:"level"`  // "debug", "info", "warn", "error" — default: "info"
    Format string `yaml:"format"` // "json", "text" — default: "json"
}
```

Create `internal/config/config.go`:
- `func Load(path string) (*Config, error)` — reads YAML file, unmarshals, applies defaults, validates
- `func Validate(cfg *Config) error` — checks required fields, validates role names, returns multi-error with all validation failures
- `func applyDefaults(cfg *Config)` — fills in default values for optional fields
- Support `${ENV_VAR}` syntax in string fields for secret injection (client_secret especially)

Create `configs/example.yaml` with all fields documented with comments showing every option.

Write tests FIRST (RED), then implement (GREEN).
