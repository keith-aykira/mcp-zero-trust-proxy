5. `crawling_exa` on pricing pages of comparable tools:
   - Lunar.dev (if pricing is now public)

   - Kong gateway pricing page
   - Cloudflare API gateway pricing
   - Other API security tool pricing pages found in searches
   - Bearer.sh, Salt Security, Wallarm, or similar API security SaaS pricing

6. `company_research_exa` on 2-3 API security companies to understand market positioning:
   - Salt Security (API security leader)
   - 42Crunch (API security)
   - Wallarm (API security)

**Data to collect:**

A. **Pricing benchmarks** -- what do comparable tools charge?
   - Tool name, pricing tiers, target buyer, pricing model (per seat, per API, per request, flat)
   - Focus on tools that are closest analogs: auth middleware, API gateways, security proxies
   - Note: free/open-source competitors exist but do not invalidate paid market

B. **Buyer segments** -- who buys security middleware?
   - Solo developers: What do they pay for? What's their budget?
   - Small teams (5-20 devs): Security tool spending patterns
   - Mid-market (20-200 devs): Compliance-driven purchasing
   - Enterprise (200+): Procurement processes, minimum viable feature sets

C. **Purchase triggers** -- what makes someone go from free to paid?
   - Compliance requirement (SOC 2, HIPAA, PCI)
   - Security incident or audit finding
   - Scale (too many servers to manage manually)
   - Team growth (need RBAC, audit trails)
   - Regulatory pressure

D. **Willingness to pay for MCP specifically**
   - Any evidence of teams paying for MCP security
   - Developer sentiment about paying for security tools
   - Price sensitivity signals
