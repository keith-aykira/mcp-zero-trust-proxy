    2. Create `supabase/migrations/20260321_create_licenses.sql`:
       ```sql
       CREATE TABLE licenses (
         id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
         email text NOT NULL,
         tier text NOT NULL CHECK (tier IN ('pro', 'enterprise')),
         stripe_subscription_id text UNIQUE,
         stripe_customer_id text,
         license_key text NOT NULL,
         max_upstreams int NOT NULL,
         max_rpm int NOT NULL,
         issued_at timestamptz NOT NULL DEFAULT now(),
         expires_at timestamptz NOT NULL,
         revoked_at timestamptz,
         created_at timestamptz NOT NULL DEFAULT now()
       );
       CREATE INDEX idx_licenses_email ON licenses(email);
       CREATE INDEX idx_licenses_stripe_sub ON licenses(stripe_subscription_id);
       -- RLS: anon can read their own license by email (for key retrieval)
       ALTER TABLE licenses ENABLE ROW LEVEL SECURITY;
       CREATE POLICY "Users can read own licenses" ON licenses FOR SELECT USING (true);
       ```

    3. Create `supabase/functions/create-license/index.ts`:
       - Deno Edge Function that generates a signed JWT license key
       - Input: `{ email, tier, stripe_subscription_id, stripe_customer_id }`
       - Read ECDSA private key from Supabase secret `LICENSE_SIGNING_KEY`
       - Build JWT claims: `{ tier, max_upstreams, max_rpm, exp (30 days from now), iss: "mcpzerotrust.dev", sub: email, iat: now }`
       - Tier limits: pro -> {5, 200}, enterprise -> {0, 0} (0 means unlimited)
       - Sign with ECDSA P-256 (ES256 algorithm)
       - Insert row into `licenses` table
       - Return `{ license_key, expires_at }`
       - Use Deno's built-in crypto.subtle for signing (no npm deps)
       - Handle errors: missing fields -> 400, signing failure -> 500
