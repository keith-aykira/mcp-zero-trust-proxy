<feature>
  <name>JWT License Key Validation and Tier Enforcement</name>
  <files>internal/license/license.go, internal/license/license_test.go, internal/config/types.go, internal/config/config.go, internal/config/config_test.go, cmd/mcpproxy/main.go</files>
  <behavior>
    - Parse("") returns a free-tier License (tier="free", no error)
    - Parse(validJWT) returns License with tier, limits, expiry extracted from claims
    - Parse(expiredJWT) returns error "license expired"
    - Parse(tamperedJWT) returns error "invalid signature"
    - Parse(wrongIssuerJWT) returns error "invalid issuer"
    - Validate(license) checks expiry, returns error if past
    - Free tier: max 1 upstream, rate limit capped at 10 req/min, audit output=stdout only
    - Pro tier ($49): max 5 upstreams, rate limit up to 200 req/min, audit file output
    - Enterprise tier ($199): unlimited upstreams, unlimited rate, all features
    - License claims: {"tier": "pro", "max_upstreams": 5, "max_rpm": 200, "exp": unix_ts, "iss": "mcpzerotrust.dev", "sub": "customer_email"}
    - Config YAML accepts `license: { key: "${LICENSE_KEY}" }` (env var substitution works via existing pattern)
    - main.go: if license invalid/expired, log.Fatal with clear message; if no key, proceed as free tier
  </behavior>
  <implementation>
    1. Create internal/license/license.go:
       - Define Tier type (string): "free", "pro", "enterprise"
       - Define License struct: Tier, MaxUpstreams int, MaxRPM int, ExpiresAt time.Time, Subject string
       - Define FreeTierLicense() returning default free limits
       - Parse(keyString string, publicKey *ecdsa.PublicKey) (*License, error):
         - Empty string -> FreeTierLicense(), nil
         - Decode JWT (3 parts, base64url), verify ECDSA P-256 signature against publicKey
         - Extract claims: tier, max_upstreams, max_rpm, exp, iss, sub
         - Validate issuer == "mcpzerotrust.dev"
         - Check exp > now
         - Return populated License
       - Use crypto/ecdsa, crypto/elliptic, crypto/sha256 from stdlib — no external JWT library
    2. Add LicenseConfig to config types.go: Key string `yaml:"key"` (supports ${ENV_VAR})
    3. Add License field to Config struct
    4. Wire in main.go: after config.Validate, call license.Parse(cfg.License.Key, publicKey).
       If error, log.Fatal. Otherwise apply tier limits as overrides:
       - Cap cfg.RateLimit.RequestsPerMinute to license.MaxRPM
       - If free tier, force cfg.Audit.Output = "stdout"
       - Log tier info at startup
  </implementation>
</feature>
